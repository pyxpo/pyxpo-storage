# Changelog

## 0.1.0a2 (2026-10-30)

- Now needs pyxpo 0.1.0a4 or newer, the first release with the web target.
- Web: the build now loads Pyodide's `sqlite3`, so storage works on the web page and persists in IndexedDB.
- Moved to its own repository, github.com/pyxpo/pyxpo-storage, with CI on Python 3.9 and 3.12 and releases from tags.
- Added a security policy, a contributing guide and issue templates.

## 0.1.0a1

- Docs: detailed README with screenshots, and fuller PyPI metadata (keywords, classifiers, project URLs).
- First release.
